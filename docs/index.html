Why Rekoto

A desktop recorder with studio framing, a clean desktop, and browser privacy — without a cloud account.

Local MP4 library

Videos land in Videos\Rekoto (or your folder). Search, play, rename, delete to Recycle Bin.

Camera bubble

Round bubble of you, four sizes, dragged where you want. Hidden from capture, drawn into the video.

Clean desktop

Wallpaper, icons, other apps, optional taskbar — swapped for the take, restored when you stop.

Browser privacy

Mask passwords and cards; crop chrome; control recording from the toolbar when the extension is connected.

Quick start

Node.js 20+ on Windows 10 (2004+) or later.

npm install
npm run icons
npm run build:ext
npm run dev
npm run dist

Installer output goes to dist/. Load unpacked extensions from extensions/chrome or extensions/firefox.
